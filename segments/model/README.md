# model

Shows the model in use and its effort level, for example `Opus 4.7 [high]`.

## Settings

| Key | Default | Meaning |
|---|---|---|
| `model.effort` | `true` | Show the effort level after the model name. |

## Depends on

- The session: the model's display name and the effort level.
- Its own config section, and a painter for the text colour.

## Layout group

Identity.
